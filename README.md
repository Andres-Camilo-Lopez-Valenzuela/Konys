# 🍕 Konys Pizza — Sistema de Reservas de Mesas (JAMstack)

Aplicación web moderna y responsiva para la gestión y reserva de mesas en tiempo real para el restaurante **Konys Pizza**. 

Desarrollada bajo la arquitectura **JAMstack** con **HTML5 semántico, CSS3 moderno (Mobile-First) y JavaScript ES6+ Vanilla**, utilizando **Supabase** como backend serverless (Database + REST API) y lista para despliegue en **Vercel**.

---

## 🚀 Arquitectura y Tecnologías

- **Frontend:** HTML5, CSS3 puro (Flexbox, CSS Grid, variables CSS, sin librerías externas), JavaScript Vanilla (ES6+).
- **Backend / Database:** [Supabase](https://supabase.com/) (PostgreSQL + API autogenerada + SDK oficial v2 vía CDN).
- **Hosting & CI/CD:** [Vercel](https://vercel.com/) (Despliegue estático continuo).
- **Autenticación:**
  - *Clientes:* Sin registro ni fricción (solo ingresan datos al reservar).
  - *Administrador:* Panel protegido en frontend mediante clave maestra con persistencia en sesión.

## 🗄️ Modelo de Base de Datos en Supabase (SQL Script)

Ingresa a tu proyecto en **Supabase** -> **SQL Editor** -> **New Query**, pega y ejecuta el siguiente script completo para crear las tablas, relaciones y datos de prueba:

```sql
-- 1. TABLA: MESAS
CREATE TABLE IF NOT EXISTS public.mesas (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    zona VARCHAR(50) NOT NULL DEFAULT 'Salón Principal',
    capacidad INT NOT NULL CHECK (capacidad > 0),
    activa BOOLEAN NOT NULL DEFAULT true,
    foto_url TEXT,
    creado_en TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 2. TABLA: HORARIOS
CREATE TABLE IF NOT EXISTS public.horarios (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    dia_semana VARCHAR(20) DEFAULT 'todos',
    jornada VARCHAR(50) NOT NULL,
    hora_inicio TIME NOT NULL,
    hora_fin TIME NOT NULL,
    duracion_slot INT NOT NULL DEFAULT 60,
    activo BOOLEAN NOT NULL DEFAULT true
);

-- 3. TABLA: RESERVAS
CREATE TABLE IF NOT EXISTS public.reservas (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    mesa_id BIGINT REFERENCES public.mesas(id) ON DELETE RESTRICT NOT NULL,
    cliente_nombre VARCHAR(150) NOT NULL,
    cliente_contacto VARCHAR(100) NOT NULL,
    num_personas INT NOT NULL CHECK (num_personas > 0),
    fecha DATE NOT NULL,
    hora_inicio TIME NOT NULL,
    hora_fin TIME NOT NULL,
    estado VARCHAR(30) NOT NULL DEFAULT 'confirmada' CHECK (estado IN ('confirmada', 'cancelada', 'completada')),
    creado_en TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- HABILITAR ROW LEVEL SECURITY (RLS) PERMISIVO PARA PROYECTO ACADÉMICO / JAMSTACK CLIENT
ALTER TABLE public.mesas ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.horarios ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.reservas ENABLE ROW LEVEL SECURITY;

-- Políticas de lectura y escritura públicas (usando ANON KEY)
CREATE POLICY "Permitir lectura mesas" ON public.mesas FOR SELECT USING (true);
CREATE POLICY "Permitir insert/update mesas" ON public.mesas FOR ALL USING (true);

CREATE POLICY "Permitir lectura horarios" ON public.horarios FOR SELECT USING (true);
CREATE POLICY "Permitir insert/update horarios" ON public.horarios FOR ALL USING (true);

CREATE POLICY "Permitir lectura reservas" ON public.reservas FOR SELECT USING (true);
CREATE POLICY "Permitir crear reservas" ON public.reservas FOR INSERT WITH CHECK (true);
CREATE POLICY "Permitir actualizar reservas" ON public.reservas FOR UPDATE USING (true);

-- 🍕 DATOS SEMILLA (SEED DATA)
INSERT INTO public.mesas (nombre, zona, capacidad, activa) VALUES
('Mesa Toscana 1', 'Salón Principal', 2, true),
('Mesa Toscana 2', 'Salón Principal', 4, true),
('Mesa Familiar Napoli', 'Salón Principal', 6, true),
('Mesa Romana Terraza 1', 'Terraza', 4, true),
('Mesa Romana Terraza 2', 'Terraza', 4, true),
('Mesa Mirador Terraza', 'Terraza', 2, true),
('Palco VIP Don Corleone', 'VIP', 8, true);

INSERT INTO public.horarios (dia_semana, jornada, hora_inicio, hora_fin, duracion_slot, activo) VALUES
('todos', 'Almuerzo', '12:00:00', '16:00:00', 60, true),
('todos', 'Cena', '18:00:00', '23:00:00', 60, true);
```
